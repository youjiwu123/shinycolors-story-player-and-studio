# 闪耀色彩 同人工坊 · Prism Studio — G3 交互前端原型

> 状态：**G3 原型**（2026-11-12，owner：`editor-proto`）。目的：在接 Phase 2 后端之前，让用户**亲手试**布局手感和视觉风格。
> 规范依据：[`docs/scproj_format_v2.md`](../docs/scproj_format_v2.md)（含 v2.1 的四个可选字段）。示例数据：[`examples/scproj/rooftop_after_rain.scpack/`](../examples/scproj/rooftop_after_rain.scpack/)。

## 怎么打开

直接双击 `index.html`（`file://` 就能跑）。**零依赖、零 CDN、零网络请求**，离线可用。推荐 Chrome / Edge 新版（用到了 `backdrop-filter`、`aspect-ratio`、`color-mix`）。

| 文件 | 内容 |
|---|---|
| `index.html` | 外壳：顶栏 + 三区工作室 + 弹窗容器 |
| `prism-proto.css` | 「晴空虹光毛玻璃 Prism Aero」视觉体系，明 / 暗主题，窄屏抽屉 / 手机布局 |
| `proto-app.js` | 全部交互：命令栈、OOC 守卫、舞台、检查器、序列化、预览、合成音 |
| `mock-data.js` | 模拟数据：示例故事逐行照搬 + 1 行故意写错的演示行；素材库 / 宏 / 称呼矩阵 / 声优短句都是模拟 |

- **✍️ 台本润色态**：台本区加宽；**🎬 舞台分镜态**：舞台放大；**✨ 脑洞扩写**：台本区顶部出现扩写面板（模拟 LLM 流式输出，结果自动过 OOC 守卫，插入后标 `origin: ai` + `_meta.ai`）。

## 建议的试用路线（5 分钟）

1. 左侧滚到第 16 行（冬優子，演示行）：三个 OOC 胶囊——⛔ 一人称（营业时说了「あたし」）、⚠ 称呼（「プロデューサーくん」）、⚠ 超长 63/54。点胶囊看修复预览 → 「一键修复」。超长修复会在中点附近的标点处**拆成两行**（新行发新 `uid`，中文同步拆）。然后按 `Ctrl+Z` / `Ctrl+Y` 来回看。
2. 点第 4 行，在舞台上**拖动冬優子**（吸附 200 / 310 / 568 / 796 / 936 站位）；拖右上角圆点或**滚轮**缩放；**再点一次**已选中的角色切换视线（`charAnim4`）。每次拖动 = 一步撤销。
3. 舞台上方滤镜条：黄昏染色 / 回忆柔焦 / 雨雾叠加 / 闪白过渡（写在当前行，向后继承）。
4. 第 6 行 → 🎙️ 配音：「抽 3 个 Take」→ ▶ 试听（WebAudio 合成示意音）→ 🔒 锁定（同时改行 `voice`，满足 V5）；每张卡可选「前置相槌」生成 v2.1 `recipe`。往拖入区丢一个本地音频，会解码出真实波形。
5. 🎨 背景：搜「下雨 公园」「傍晚 事务所」；点提示词预设 → 「生成 4 张候选」→ 点一张即登记为 `pack.assets.bg[id]`（带 `imageGen`、`refBgId`、`stageFilter`、`outputs`）并上舞台；也可以拖入本地图片。
6. 🎵 BGM · 源码：`.scs.yaml` / `.scproj.json` 实时双向——在文本框里改一个字，0.6 秒后应用到文档（进撤销栈）；写错语法会报行号，**不会**污染文档。
7. 包选择器切到「放学后的彩排」：3 人站位 + 称呼 / 一人称错误演示；选项行在舞台上点按钮可以跳转；`▶ 连续预览`（空格）自动播放、按选项分支。
8. 🎥 导出：先跑 V3 / V4 / V5 / V6 / V7 / V12 / V15 / V17 + OOC 检查，再下载 `.scproj.json`（规范形）/ `.scs.yaml` / 官方裸数组（删 `_meta`）/ `pack.json`；MP4 是模拟进度。

## 和 scproj v2 规范的对应

| 规范要求（§9 editor-proto） | 原型做法 |
|---|---|
| 读写 envelope，保留未知键和官方键顺序 | 文档模型就是 envelope；改已有键原位赋值；新键追加后把 `_meta` 挪回行末 |
| 新行发新 `uid`，不重编号 | 新行 / 拆分行 / 复制行 / 宏 / 扩写都发 `u…` 新 uid；行身份用编辑器内部 key，不写进数据 |
| 输出规范形 | 导出与源码视图：官方键原顺序 + `_meta` 在行末且键按码点排序 |
| 改官方行设 `origin:"edited"`；宏内编辑去掉 `macroId` | `mutRow()` 比较官方字段签名，变了就处理（整段宏实例一起脱离，并提示） |
| 不产出 XML `<beat>` | 没有任何 XML 输出 |
| 包内不得有凭据（V12） | ⚙ 云端接口只存浏览器 localStorage（模拟宿主配置）；导出前扫描凭据键 |
| v2.1：`holdMs` / `takes[].recipe` / 包展示字段 / `@none` | 潜台词页的停顿滑块 + 智能默认；配音卡的前置相槌；页头显示 `unit` / `synopsisZh`；简写解析支持 `@none` / `@off` |

编辑器扩展键（都在 `_meta` 下，按 §3.3 走 `x-*`）：`x-editor-filter`（舞台滤镜：`none|dusk|memory|rain|flash`）。

## 快捷键

`Ctrl+Z` / `Ctrl+Y`（或 `Ctrl+Shift+Z`）撤销 / 重做 · `空格` 连续预览 · `↑↓` 选行 · `Alt+↑↓` 移动行 · `Enter`/`F2` 编辑 · `Ctrl+Enter` 插入台词 · `Delete` 删行 · `Alt+1…4` 切检查器分页 · `Esc` 关闭 / 停止。顶栏数字按钮 = 操作历史，点任一条可以跳回那一步。

## 已知限制（Phase 2 再做）

- 立绘是 SVG 示意小人（按角色示意色），不是官方 spine；官方背景是占位画，只有示例包的 `rooftop_after_rain.png`（渐变占位图）是真实文件。
- 配音 / BGM / SE 都是 WebAudio 合成示意音；生图 / LLM / TTS 全部模拟，不发网络请求。
- `.scs.yaml` 视图是 §4.7 的 **verbatim 反编译**，每个条目一行流式映射；解析器只认这种单行形式（外加 say 字符串和 `#` 指令）。完整 YAML 1.2 块语法和 author 模式自动补全（A1–A7、v2.1 说话人自动解析）在 Phase 2 直接移植 `examples/scproj/_ref/scs_ref.js`。
- 草稿自动存到浏览器 localStorage（按包分开）；拖入的图片 / 音频只在内存里，刷新就没了。切换包会清空撤销历史。
- 包选择器里的「打开本地 .scproj.json…」可以载入 envelope 或官方裸数组，但素材按当前包解析。

## 自检

`window.SCProto` 暴露了 `S / undo / redo / stageAt / checkLine / toYaml / toScprojText / toOfficial / parseYamlDoc / runChecks`，方便在控制台验收。原型自带的无头浏览器冒烟测试覆盖：整页无滚动（1600×900 / 980×760 / 390×844）、OOC 修复 + 撤销重做、打字合并成一步撤销、拖拽 / 滚轮 / 视线、抽卡 + 锁定（V5）、语义搜背景、生图登记、宏插入、YAML 编辑应用 + 语法错误拦截、扩写插入、连续预览、导出检查，且控制台 0 报错。
